First public build of **Polaris**, an Android stargazing companion that tells you whether tonight is worth taking the telescope out.

## What's new
- **Tonight**: explained 0–100 scores for general stargazing, Moon, planets and deep sky, based on Open-Meteo forecasts and on-device astronomy. Every factor is labelled Model / Forecast / Estimated / Calculated / User-provided / Unavailable.
- Best observing windows, an hour-by-hour outlook until sunrise, current weather (cloud layers, dew point, wind, jet stream, precipitation, visibility), twilight times and Moon phase/rise/set.
- **Sky**: interactive polar sky map and a ranked list of what is above the horizon.
- **Explore**: searchable catalog of about 85 objects (planets, bright stars, Messier/NGC highlights) with rise/transit/set.
- **Telescope (experimental)**: phone-sensor orientation, declination correction, one-star alignment and a push-to guide.
- **Settings**: device or manual location, Bortle class, units, auto-refresh.
- Offline support: astronomy works fully offline, and weather is cached with clear "cached / offline" indicators.

## Install
Two APKs are attached:

| File | Use it for |
|---|---|
| **`polaris-v0.1.0.apk`** | **Recommended.** Release build, signed with the Polaris release key and minified (~1.7 MB). App id `io.github.jimthefatjam.polaris`. |
| `polaris-v0.1.0-debug.apk` | Debug build for testing (~18 MB). App id `io.github.jimthefatjam.polaris.debug`, so it installs alongside the release build. |

1. Download `polaris-v0.1.0.apk`.
2. Allow "Install unknown apps" for your browser or file manager.
3. Open the APK and install it. Requires Android 8.0+ (API 26).

Checksums are in `SHA256SUMS.txt`. The release signing certificate's SHA-256 is
`29:B1:14:E7:34:3B:51:CE:4B:26:30:70:54:2D:9C:77:46:50:90:E7:FA:18:A8:26:95:D6:0B:B7:12:1F:78:CE`.

## Known limitations
- Seeing and transparency are *estimates* (jet-stream wind, humidity, visibility). No public weather API measures them.
- Light pollution comes from a Bortle class you choose in Settings.
- Telescope pointing is accurate to a few degrees at best and needs alignment.
- Weather depends on Open-Meteo's free tier (rate limits are handled with caching and back-off).

## Deferred to future versions
Clear-sky notifications, constellation lines and a larger catalog, observing logs (Room), ISS/satellite passes, a light-pollution map lookup, two-star alignment, camera plate solving.
